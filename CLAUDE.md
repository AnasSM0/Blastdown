# CLAUDE.md

This compatibility file is retained for tools that automatically inspect
`CLAUDE.md`. It does not assign repository ownership or engineering authority.

BlastDown's current governance is defined by `AGENTS.md`. Codex is the sole
engineering agent for the current build, while product direction comes from
the approved document hierarchy beginning with `docs/PRD.md`.

Historical Claude/Codex ownership text in archived plans and decision records
describes how earlier work was performed. It is not a current instruction and
must not override `AGENTS.md` or the approved product documents.
