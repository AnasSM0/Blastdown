# CLAUDE.md

This file is read automatically by Claude Code. It does not define governance
itself: BlastDown's current rules live in `AGENTS.md`, and every rule there
applies to work done from this file.

Claude Code is the sole engineering agent for the current build, while product
direction comes from the approved document hierarchy beginning with
`docs/PRD.md`. The handover from Codex is recorded in `docs/DECISIONS.md`
(2026-10-12).

Historical Claude/Codex ownership text in archived plans and decision records
describes how earlier work was performed. It is not a current instruction and
must not override `AGENTS.md` or the approved product documents.
