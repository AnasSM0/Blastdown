# UI Reference Manifest

Human-readable index of the 16 Stitch screens approved as BlastDown's visual
direction. Machine-readable index with checksums/paths:
`docs/references/ui/stitch-mcp/manifest.json`. Full retrieval provenance:
each screen's `docs/references/ui/stitch-mcp/NN-slug/metadata.json`.

Stitch project: **BlastDown Puzzle UI Design**
(`projects/4472195625883229066`). Retrieved 2026-07-18.

**Stitch is authoritative for visual direction only.** Gameplay accuracy of
each screen is evaluated in `docs/UI_REFERENCE_AUDIT.md` — read that
alongside this manifest before treating any single screen as ready to
implement verbatim.

## Screens the approved list does not cover

The Stitch project has 65 total screens (see the earlier project survey);
only the 16 above were approved for this ingestion. Notably **not**
included: Settings screen, Themes screen, a plain Home-only "normal
gameplay" reference without the "Neon Reactor Minimal" qualifier, and any
screen depicting rubble in a post-explosion board state. If/when those are
approved, re-run the retrieval and extend this manifest and
`docs/references/ui/stitch-mcp/manifest.json` — don't hand-add screens
outside the retrieval process, so provenance (checksums, timestamps) stays
accurate.
