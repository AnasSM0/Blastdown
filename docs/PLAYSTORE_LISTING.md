## Full description

BlastDown is a strategic block puzzle where every placement can change the
board—and every countdown block raises the pressure.

Fit shapes onto an 8×8 grid and complete rows or columns to clear space. Plan
ahead through each three-piece hand, build combos, and keep the board open as
the score climbs.

Countdown blocks add a dangerous twist. Clear their cells in time to defuse
them naturally. Let a timer expire and the blast leaves rubble behind, turning
your next move into a new puzzle.

When the board gets tense, optional rewarded actions can help:

- Freeze pauses active countdowns for a limited number of placements.
- Defuse safely removes a live countdown threat.

Ads are always player-initiated, never interrupt the core loop, and are not
required to play.

Features:

- Endless strategic block-puzzle play
- Clear full rows and columns
- Countdown threats, explosions, and rubble
- Score, combos, and local best score
- Continue an active run after closing the app
- Fast, replayable sessions
- Sound, music, haptics, and reduced-motion settings
- A guided first-run tutorial you can replay anytime
- Offline core gameplay; rewarded ads require a network connection

Place carefully. Read the timer. Keep the grid alive—and see how long you can
hold back the blast.
